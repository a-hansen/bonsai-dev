# Bonsai Prompts

This guide routes to the prompts available in the same resolved Bonsai Home. `specification.md` remains
authoritative; load a prompt only for its entry workflow.

| Prompt | Responsibility / when to load |
| --- | --- |
| `<bonsai-home>/prompts/create_map_repo.md` | Turn a Web UI source-owner conversation into optional human-owned code-map calibration. |
| `<bonsai-home>/prompts/create_project_memory.md` | Turn a mature Web UI design conversation into durable Bonsai project memory. |
| `<bonsai-home>/prompts/implementation.md` | Route coding-agent startup, authorization gates, implementation, reconciliation, and handoff after bootstrap identity resolution. |
